# Interactive plan navigation

The PDF viewer fits the page, supports direct page selection and repeat navigation from a unit card. Overlays are hidden until the matching PDF page and zoom finish rendering. Unfinished boundary drawings block changing the page or floor until linked or cleared.

Filter units by floor, mapped/unmapped status, or current PDF page. The mapping counter shows actual persisted shapes. Published readers with inventory.read can see all project unit cards, including unmapped units; draft price fields remain redacted. PDF code markers accept slash/dash variants only for one unambiguous project unit. Overlay status colors always come from current inventory.
