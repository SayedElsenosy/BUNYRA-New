# Posted-ledger financial statements (2026-10-22)
The accounting report now includes period P&L and point-in-time balance sheet derived solely from posted ledger lines, scoped by company, legal entity, and optional project. BigInt arithmetic preserves signed balances. The balance sheet queries cumulative postings through To, while the P&L queries activity only between From/To. Results remain unaudited EGP reports and require opening balances to be complete. Project-filtered statements may not independently balance when some journal legs omit project dimensions. Neither this implementation nor CI publishes to Cloudflare or migrates production data.
