# مراجعة متطلبات BUNYRA — 20 أكتوبر 2026

راجعت صفحات الملف الـ26 ونصوص الطلبات الـ59 والمراجع البصرية الستة، وقارنتها بالكود عند main a9974e7982ca6e6b226034cbc84cb5188dd64b0d. هذه مراجعة تنفيذ أولية وليست شهادة قبول شاملة أو اختبارًا جديدًا لكل الوظائف القديمة. «موجود أساسه» يعني وجود كود واختبارات سابقة، ولا يعني اكتمال جميع معايير الملف.

## قرارات التنفيذ

- أولوية الملف الجديد تسبق المحاسبة الموسعة.
- الإبقاء على هوية BUNYRA الكحلي والذهبي؛ مراجع 8X للإلهام في الترتيب والتفاعل فقط، دون نسخ العلامة أو الأسعار أو اختلاق مؤشرات.
- الحسابات ينشئها المالك ومسؤول الشركة داخليًا، مع الحدود والصلاحيات؛ لا إعادة لدعوات خارجية تخالف طلب المستخدم.
- لا استكمال لتوزيع الوحدات على المخطط التجريبي قبل الملف الهندسي الأساسي.
- لا AI ولا ترحيل بيانات حقيقية أو موافقات مالية تجريبية في الإنتاج.

## أول دفعة

ربط ظهور الأقسام بصلاحيات الخادم الفعلية مع دعم المنع والأدوار المخصصة وصلاحيات المشروعات، وحفظ الشركة والقسم في الرابط للمالك وحساب الشركة، ودعم التحديث والرجوع والتقدم. لا يُحمّل قسم غير مسموح نتيجة تغيير رابط يدوي. تبقى حماية API مستقلة.

هذه الدفعة تقدم BN004 وBN007 وBN012 وBN058 ولا تدعي إتمامها: المفضلة، روابط السجلات، حفظ فلاتر وصفحات كل شاشة، وباقي E2E ما زالت لاحقة.

## ترتيب العمل بعد هذه الدفعة

1. لوحات الأدوار BN008، البحث الموحد BN009، مهامي BN010، وحالات واجهة موحدة BN011.
2. Customer360 وKanban وإجراءات التواصل وSLA ثم مستكشف الوحدات ورحلة الطلب والعرض والحجز.
3. صناديق الموافقات والتحصيل وDeals Insights والرسوم والتصدير.
4. مركز الإشعارات، التكاملات المختارة والتقويم والاستيراد الموسع.
5. ERP المحاسبي ثم الاشتراكات، مع استكمال اختبارات العزل والحمل والاستعادة والتشغيل حسب الأولوية قبل الإطلاق العام.
