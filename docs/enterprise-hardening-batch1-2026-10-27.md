# الدفعة الأولى لتقوية BUNYRA — 27 أكتوبر 2026

هذه تغييرات في الكود والترحيلات، وليست إعلانًا بتفعيلها على الإنتاج. لم يُغيّر حساب أو ملف أو سجل تشغيل، ولم تُطبّق ترحيلات على Neon أو يُنشر Worker.

## التغييرات المنفذة

| نتيجة المراجعة | التنفيذ |
|---|---|
| A01: تغيير كلمة مرور حساب أعلى صلاحية | تغيير أي كلمة مرور يتطلب `members.manage` على مستوى الشركة أو وصول مالك منصة موثق. موظف العمليات يحتفظ بتعديل بيانات الحساب فقط. تعديل الملف الشخصي لا يكتب password hash قديمًا، فيحمي تغيير كلمة المرور المتزامن. |
| A02: تجاوز منع مشروع في التقرير المجمع | التقرير الكامل يُرفض عند وجود منع مالي لأي مشروع. التقرير المحدد لمشروع مسموح يستمر. لا تعرض الخدمة ميزانية جزئية وكأنها قائمة كاملة. |
| A03: تغير العقد عند إعادة التوليد | لقطة ثابتة لبيانات التعاقد والأقساط والقالب عند اكتمال معاملة إنشاء العقد، وملف Word محفوظ مرة واحدة ببصمته. كل تنزيل يعيد التحقق من الصلاحيات وسلامة الملف. |
| A04: الاعتماد والتنفيذ الذاتي | مقدم الطلب لا يعتمد تسويته، والمعتمد لا ينفذها. يسمح للطالب بالتنفيذ بعد مراجعة شخص مستقل؛ السياسة تتطلب شخصين على الأقل ولا تفرض ثلاثة موظفين. لا يوجد استثناء لمالك المنصة. |
| A05: ضياع أصل المستند | الاستبدال يحفظ الملف والصف السابقين كإصدار `superseded`، مع إصدار حالي واحد. بعد تقديم الحجز يلزم أيضًا حق الاعتماد. بيانات الملفات الأصلية محمية من التعديل والحذف عبر الدور المحدود. |
| A14: تنظيف ملفات القوالب | ملفات القوالب تدخل طابور التنظيف عند الحذف المسموح. الشركات التي لديها لقطة عقد ثابتة لا تُمحى معها الأدلة القانونية؛ تستمر سياسة الاحتفاظ. |
| A07: فحوص قبل الإصدار — تحسن جزئي | اختبارات الخدمات الجديدة وتطبيق جميع الترحيلات واختبارات PostgreSQL الأمنية أصبحت ضمن CI المطلوب قبل مهمة النشر، وتعمل أيضًا على pull requests. اختبارات Neon الشاملة وUAT والمتصفح ما زالت تحتاج تجهيزًا مستقلًا. |

الحماية تمتد لقاعدة البيانات: لا يستطيع الدور المحدود تعليم التسوية «منفذة» بتحديث مباشر يتجاوز أثرها على الأقساط. التنفيذ يمر بدالة تتحقق من الهوية والصلاحية والمشروع والاعتماد المستقل، ثم تعدل الأرصدة والتدقيق داخل العملية المحمية. الدالة الداخلية غير متاحة له.

بيان ملف Word يتحقق من هوية الناشر وصلاحيته للسجل ومسار الملف داخل الشركة والعقد ووجود لقطة وقالب وجدول صالحين. PostgreSQL لا يقرأ بايتات التخزين؛ بصمة المحتوى تظل مسؤولية خدمة التوليد الموثوقة وتُراجع عند التنزيل.

## تغييرات السلوك التي يجب معرفتها

- كلمة المرور لا تظهر في تعديل الحساب لموظف العمليات. إدارة الأعضاء هي الجهة المخولة بإعادة تعيينها حتى لحساب مبيعات عادي.
- صاحب منع مشروع لا يحصل على تقرير مالي شامل؛ يختار مشروعًا مسموحًا أو يرجع لمن يملك صلاحية التقرير الكامل.
- العقود السابقة للترحيل 073 لا تُملأ بلقطة مأخوذة من بيانات اليوم. تنزيلها يرجع `CONTRACT_WORD_SNAPSHOT_REQUIRED` مع رسالة مفهومة؛ يلزم مسار مراجعة للنسخ القديمة أو إعادة الإصدار، ولم يُنفّذ في هذه الدفعة.
- العقد الجديد دون قالب وقت التعاقد لا يستخدم قالبًا مضافًا لاحقًا بأثر رجعي؛ يرجع `TEMPLATE_NOT_CONFIGURED_AT_SIGNING`.
- لقطة عقد أُنشئ خارج خدمة التعاقد بجدول أقساط فارغ لا تتبنى جدولًا أُضيف لاحقًا. تنزيلها مرفوض. خدمة التعاقد الطبيعية تنشئ الجدول داخل نفس المعاملة.
- التسويات القديمة التي اعتمدها نفس مقدمها لا يمكن تنفيذها بعد الحماية الجديدة. لم تُعدّل تاريخيًا؛ يلزم إجراء تصحيح ومراجعة مستقل قبل التعامل معها.
- ملفات Word الناتجة ثابتة؛ تعرض وضع الأقساط وقت التعاقد، وليست كشف حساب المدفوعات الحالي.
- إذا رفع التخزين الملف ثم تعذر تأكيد نتيجة تسجيله في DB، لا تحذف الخدمة الملف عشوائيًا؛ قد تكون المعاملة التزمت قبل انقطاع الرد. مراجعة وتنظيف الملفات غير المرتبطة بشكل آمن عمل تشغيلي لاحق.

## التحقق

- `npm run test:enterprise-security`: **61 اختبار سلوك** لخدمات المصدر باستخدام SQL وتخزين وهميين: الحسابات 14، التقارير 16، إصدارات المستندات 8، الاعتمادات 14، نسخ العقود 9.
- `npm run test:enterprise-db`: ينشئ PostgreSQL 17 مؤقتًا في Docker محلي، دون شبكة ودون ربط منفذ، على تخزين tmpfs. يتجاهل DATABASE_URL وأي إعداد اتصال خارجي. نجح في تطبيق **73 ترحيلًا** وتنفيذ **50 اختبار SQL فعليًا**، ثم أعاد المعاملة وحذف حاويته.
- أُعيد تشغيل مجموعات الفحص المحلية السابقة: **161 فحصًا** ناجحًا؛ بعضها اختبارات مصدر ثابتة وبعضها اختبارات سلوك، وليست كلها تكامل قاعدة بيانات.
- `npm run typecheck`: ناجح.
- `npm run build:cloudflare`: ناجح. ظهرت تحذيرات bundler في كود مكتبات معالجة الصور عن `??` وcase مكرر؛ لم تمنع البناء ولم تُعدّل المكتبات في هذه الدفعة.
- `npx wrangler deploy --dry-run --outdir .sites-runtime/enterprise-worker-check`: ناجح، دون نشر.
- فحوص المصدر الثلاثة لمراحل الدمج التشغيلية و`git diff --check`: ناجحة.
- اختبارات Neon البعيدة ورحلات المتصفح لم تُشغّل، ولا توجد نتيجة تشغيل إنتاجي مُدّعاة هنا.

لا تحذف الأعمدة والجداول أو تعكس الترحيلات لإرجاع واجهة قديمة: بعد حفظ لقطة قانونية أو إصدارات مستندات، الرجوع يجب أن يحتفظ بها. تغيير التطبيق دون خطة توافق قد يفقد إتاحة البيانات أو يواجه قيود الحماية الجديدة.
